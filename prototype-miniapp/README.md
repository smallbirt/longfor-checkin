# 每日签到 · 微信小程序交互原型

独立的静态手机网页原型，支持多程序、多账号、独立计划、登录更新、运行记录和通知设置。没有业务 API，也不会发送真实签到、短信或通知。

## 本地预览

```bash
cd /Users/wpy/Documents/ChatGPT/longfor-checkin/prototype-miniapp
python3 -m http.server 18093 --bind 127.0.0.1
```

浏览器打开 http://127.0.0.1:18093/ 。手机访问需要另行开放局域网监听和使用电脑的局域网地址。

所有静态资源均在本目录，不依赖 CDN、构建工具或现有 Flask 服务。已发布视频通过明确的外链打开，原型不修改已有手册或视频。

## 体验路径

- 首页查看今日进度、待处理账号、下一次执行及最近五条记录。
- “我的签到”右上角 `+` → 龙湖 App → 昵称 → 示例登录文件校验 → 确认计划 → 完成添加。同一类型可反复添加。
- 账号详情中修改昵称、时间或自动计划开关；其他实例不受影响。
- 更新登录：App 可用示例 HAR 或演示短信（先获取验证码，填 `123456`）；小程序使用示例 HAR。失败保留原状态。
- 账号详情底部“演示执行场景”可模拟签到失败、查询异常和登录失效。签到成功后主要操作改为查看今日结果，仍可复核状态。
- “我的”→ 通知设置：配置 QQ/163 接收邮箱、模拟企业微信绑定、修改提醒偏好、演示通知失败与重试。
- “我的”底部“原型演示工具”可体验无账号的首次使用状态，或恢复预置五个账号。

## 数据模型和边界

- `programTypeId` 标识程序类型：`longfor_app`、`longfor_mini`。
- `accounts[].id` 是每次添加生成的独立实例编号。账号计划、状态及运行记录通过实例编号关联，不能用程序类型作为唯一账号键。
- 演示数据只保存在浏览器 `localStorage` 的 `daily-checkin:prototype:v1` 项中。禁止填写真实凭证；页面没有真实文件上传入口。
- 时间与日期按 `Asia/Shanghai` 计算，计划仅用于展示，不创建浏览器或后台定时任务。
- 邮箱只配置收件地址，不收集邮箱密码或 SMTP 授权码。企业微信绑定仅为视觉与流程模拟，不能取得龙湖登录授权。
- 未来真正接入微信小程序时，需要独立实现原生页面、后端多实例模型、任务调度及经验证的授权/通知流程。此目录不是可直接提交审核的小程序包。
